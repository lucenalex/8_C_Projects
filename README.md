## Uso

Cada projeto possui sua própria estrutura e pode exigir Code::Blocks ou um compilador C, conforme o caso. **Não foi realizada compilação nesta curadoria**. Verifique dependências, dados de entrada e comportamento antes de executar; programas antigos não devem ser presumidos seguros para uso em produção.

## Organização e direitos

Preservar as fontes `.c`, projetos `.cbp`, documentos, dados originais e exemplos; propor remoção somente de saídas reprodutíveis depois de verificar compilação. As regras do `.gitignore` não removem arquivos já versionados.
